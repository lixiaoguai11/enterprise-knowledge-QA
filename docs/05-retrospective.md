# 05 — 复盘与下一步

## 最难的问题

知识问答的难点不只是找到相似文本，而是确认引用原文支持哪项结论，并识别“两个来源都相关但不能判定谁优先”的情形。只检查引用是否存在不足以证明整段回答都被引用支持，因此 Agent 需要在召回后读原文，并将范围/优先级作为明确的资料缺口。

## 学习收获

- Agent 只有只读检索和原文工具，能减少无关业务操作和副作用。
- 工具调用 Trace 与引用白名单让回答过程更容易复核。
- 检索指标、模型决策测试和真实模型运行结果应分开记录，不能以模拟结果冒充在线表现。

## 下一步

1. 增加通用的冲突候选抽取与人工审核评测集，测量冲突漏检率。
2. 扩展改写问题和长文档切片的召回评测，记录 BM25/混合/Rerank 对照。
3. 加入真实 DeepSeek 运行 Trace，记录模型版本、日期、输入资料版本及失败案例。
4. 若接入真实企业资料，再增加访问控制、审计、加密与数据保留策略；当前合成演示版不包含这些能力。
